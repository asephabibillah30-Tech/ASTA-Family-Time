# 🎴 ASTA Family Time - Platform & Super-App Game Keluarga Indonesia

> **“ASTA - Aktivitas • Senyum • Tawa • Apresiasi - Satu aplikasi, lebih banyak waktu bersama Keluarga.” ❤️**

Platform & Super-App Game Keluarga Indonesia yang ceria, hangat, lucu, edukatif, dan ramah keluarga. Dilengkapi 5 Game Keluarga Lengkap (Game Kartu ASTA 350+ Kartu, ASTA UNO Card Party, Monopoli Jelajah Indonesia, Ludo Klasik Ceria, Ular Tangga Petualangan) serta 13 Fitur Family Hub Terpadu.

---

## ✨ Fitur Utama

- 🎴 **50 Kartu Tantangan Lengkap** dalam 7 Kategori:
  1. 😂 **Ekspresi & Gaya**
  2. 🎭 **Tebak Gaya** (Charades)
  3. 🧠 **Tebak Kata** (Word Guessing with forbidden words)
  4. 🕺 **Gerakan & Aktivitas**
  5. 📚 **Pengetahuan**
  6. ❤️ **Kasih Sayang**
  7. 🎨 **Kreatif**
- 🎮 **5 Mode Permainan**:
  - 🎴 *Mode Acak* (Semua 50 kartu)
  - 😂 *Mode Lucu* (Ekspresi, Tebak Gaya, Gerakan)
  - 🧠 *Mode Pintar* (Tebak Kata & Pengetahuan)
  - ❤️ *Mode Keluarga* (Kasih Sayang & Kreatif)
  - ⚡ *Mode Cepat* (Batas waktu hitungan mundur 10 detik)
- ⏱️ **Timer Interaktif**: Circular SVG progress countdown dengan audio tick, alarm, dan tombol tambah waktu (+5s).
- 🏆 **Sistem Poin Dinamis**:
  - ❤️ *Berhasil! (+Poin)*
  - 😄 *Lucu Banget! (+Bonus Poin)*
  - ⏭️ *Lewati*
- 👑 **Podium & Hujan Konfeti**: Selebrasi juara 1, 2, 3 dengan efek konfeti meriah dan pesan keluarga.
- 🔊 **Synthesized Web Audio SFX**: Efek suara kartu, timer, applause, dan fanfare tanpa perlu unduh file MP3 eksternal (100% offline-ready).
- 🌓 **Mode Gelap & Mode Terang**.

## 💻 Cara Menjalankan Secara Lokal

1. **Clone repository:**
   ```bash
   git clone <URL_REPOSITORY_ANDA>
   cd family-time
   ```

2. **Install dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```

4. **Buka browser di:**
   ```
   http://localhost:5173
   ```

5. **Build untuk produksi:**
   ```bash
   npm run build
   ```
